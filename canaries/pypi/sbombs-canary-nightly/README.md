# sbombs-canary-nightly

Test fixture for supply-chain policy testing. Do not depend on this package.

Published once per day (06:00 UTC) so that a version of every age is
always available for testing supply chain policies across various policy engines.
See [`agents.md`](../../../agents.md) at the repository root for full context and rules.

This package contains no install scripts, no network calls, no file
writes, and no runtime dependencies.
